# GymSync

Plataforma web para la gestión de un gimnasio. Digitaliza membresías, pagos y control de acceso, y conecta el equipo físico con instrucciones digitales mediante códigos QR.

## Qué hace

- **Membresías y clientes:** registro, planes mensual/anual, estado de membresía e historial de pagos.
- **Control de acceso por QR:** solo entran miembros con membresía vigente. El estado se valida siempre en el backend.
- **Videos instructivos:** cada máquina tiene un QR que abre su video explicativo (YouTube privado).
- **Aforo en tiempo real:** el administrador ve la ocupación del gimnasio al instante.
- **Pagos:** cobros recurrentes con Recurrente y vencimiento automático de membresías.
- **Panel administrativo:** gestión de clientes, QR de máquinas, videos, ingresos y alertas.
